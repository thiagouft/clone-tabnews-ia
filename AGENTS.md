# AGENTS.md

## Sobre o projeto

**clone-tabnews-ia**: clone do [TabNews](https://tabnews.com.br) desenvolvido para o [curso.dev](https://curso.dev), implementado com a ajuda de agentes de IA.

## Stack

- Next.js com App Router
- React
- JavaScript (sem TypeScript)

## Comandos

- `npm run dev`: servidor de desenvolvimento
- `npm run build`: build de produção
- `npm start`: servidor de produção (depois do build)

## Convenções

- Idioma do projeto: português (pt-BR), inclusive nas mensagens de commit
